# Learning React

This repository contains a collection of React.js projects created while learning modern React development. 
Each project focuses on understanding core React concepts, improving problem-solving skills, and building reusable UI components using best development practices.

The projects cover React Hooks, state management, props, event handling, Tailwind CSS integration, and real-world mini applications.

---

## Projects Included

### Counter App
- Increment and decrement counter
- React State (`useState`)
- Event handling
- Component rendering

---

### Tailwind Props Demo
- Passing data using Props
- Reusable Components
- Tailwind CSS styling
- Component composition

---

### Background Changer
- Dynamic background color switching
- React Hooks (`useState`)
- Event-driven UI updates
- Responsive interface

---

### Password Generator
- Generate secure random passwords
- Adjustable password length
- Include Numbers
- Include Symbols
- Copy password to clipboard
- React Hooks (`useState`, `useEffect`, `useCallback`, `useRef`)

##  Getting Started

Clone the repository

```bash
git clone https://github.com/vishalkumar454/Learning-React.git
```

Move into any project folder

```bash
cd 02-Counter
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```
